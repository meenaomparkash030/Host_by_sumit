# SHAPPNO VPS — Ultimate Hosting Platform

## Features
- ✅ Admin Panel with full user management
- ✅ User System with bcrypt authentication
- ✅ Two-Factor Authentication (TOTP)
- ✅ Redeem Code System
- ✅ Discount Coupons
- ✅ Server Management (Create, Start, Stop, Delete, Clone)
- ✅ GitHub Deploy
- ✅ Custom Domains with SSL
- ✅ Environment Variables
- ✅ File Manager
- ✅ Package Manager
- ✅ Real-time Logs
- ✅ Backup & Restore
- ✅ Multi-Platform Support (20+ platforms)

## Quick Start

```bash
# Clone repository
git clone https://github.com/shappno/shappno-vps.git
cd shappno-vps

# Install dependencies
pip install -r requirements.txt

# Initialize database
python manage.py init_db

# Run
python app.py
